ABOUT

Performance Manager for Firefox

Version 1.0.1 · Developed by Mihai Lungu

This extension works locally in Firefox. It does not collect or transmit browsing data.

About RAM limits: Firefox WebExtensions cannot directly impose a 1 GB / 2 GB process-memory limit like an internal browser resource controller. This extension manages tab state and inactivity instead.
