# Performance manager for firefox

Version 1.0.1 — First release
-----------------------------

Performance Manager for Firefox 1.0.1 is the first release of the extension. It automatically unloads eligible inactive tabs to help keep Firefox responsive and reduce memory pressure during everyday browsing.

* Automatic sleeping of inactive tabs after a configurable timeout
* Individual inactivity tracking for each tab instead of one global timer
* Smart Memory Modes: Balanced, Aggressive, Maximum Savings and Custom
* Maximum Awake Tabs to control how many tabs remain loaded
* Protected tabs for active, pinned, audible, loading and private tabs
* Per-site rules with custom sleep time or Always Awake protection
* Quick actions to sleep selected percentages of eligible inactive tabs or free memory immediately
* Tab Performance Manager with live tab state and manual sleep controls
* Activity Log showing sleeping, restored, skipped and cleanup events
* Persistent local settings and activity history stored in Firefox
* Toolbar badge showing the number of sleeping tabs
* No analytics, telemetry, tracking, advertising or external servers
* No hard Firefox RAM limit is claimed; the extension reduces resource usage by unloading eligible inactive tab content
